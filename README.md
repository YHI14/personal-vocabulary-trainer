# Personal Vocabulary Trainer

個人の英単語・英語表現学習のために作ったWebアプリの、応募用ソース抜粋です。学習教材と実際の学習履歴は含めていません。

## できること

- XLSX / CSV教材の取り込みと列の対応付け
- Recognition、Cloze Select、Cloze Input、Recall、Productionの学習モード
- 回答履歴、苦手語、復習予定、習熟状況の管理
- JSONバックアップと復元

## 構成

ブラウザ側はネイティブJavaScriptのES ModulesとCSSです。`dist/`に画面、問題生成、取り込み、保存用のコードがあります。`worker/`にCloudflare WorkerのAPIとD1リポジトリ、`drizzle/`にテーブル定義があります。`scripts/build-application.mjs`はWorker用の成果物を生成します。

初期版ではIndexedDBを使用しましたが、ブラウザごとにデータが独立しました。現在の版は、所有者限定のSitesアクセス制御の下で、Cloudflare D1を学習データの保存先とし、`/api/repository`経由で読み書きします。API自身には一般公開向けのユーザー認証がありません。**このコードを公開サイトとしてそのままデプロイしないでください。**

## 応募用に除外したもの

- 個人の学習履歴、D1の実データ、バックアップ
- 元の教材サンプル（XLSX、問題設定JSON、テスト用教材行）
- SitesのプロジェクトIDと接続設定、実環境の検証記録
- 元データに依存するテストと検証レポート

そのため、このリポジトリは実際に動いているアプリの**コード閲覧用**です。動作の確認には、個人データを映さない短いデモ動画を別途用意します。手元で動かす場合は、自分の教材と安全な認証付きの保存先が必要です。

## 開発時の判断と検証範囲

教材の選定、学習メニュー、習熟度の基準と画面の構成は利用者本人が決め、AIを使って実装しました。SafariとChatGPT内ブラウザで学習データが共有されない問題を利用中に発見し、ブラウザ内保存から共通の保存先への変更を要求しました。独立したAPI接続から同じデータを取得でき、アプリ更新後も保持されることを検証しています。実機のSafariとChatGPT内ブラウザで最終的な相互照合を完了したとは主張しません。
